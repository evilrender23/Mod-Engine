# Escaparate S1

Proyecto de ejemplo de los assets **fuente**, **nota** y **tile set**.

## Qué probar
- [x] Fuentes TTF en negrita, sin antialias y de sprite
- [x] Tile set con separación, tiles animados y auto tile
- [ ] Pintar suelo con clic izquierdo (auto tile) y borrar con el derecho
- [ ] Mover la bola con las flechas: choca con los tiles (`tile_meeting`)

> Las notas no se usan en el juego: son para el equipo.

```
tilemap_autotile("Mundo", "suelo", cx, cy, true)
```
